# LaptopHub — ما اللي اتغيّر

## للمستخدم اللي مش فاهم في اللابتوبات
- **Hero section** في الأول بيشرح فكرة الموقع بسرعة، وفيه زرار "Take the 2-question quiz" و"Browse everything".
- **"New here? Start here"** في الناف بار — دليل مبتدئين (CPU, RAM, SSD, GPU, Display, Warranty) بلغة بسيطة.
- **Spec Fingerprint** — 4 بارات (Power / Graphics / Portable / Value) بتترجم المواصفات لصورة بصرية سريعة على كل كارت وفي صفحة التفاصيل، بدل ما اليوزر يفهم "12th Gen i5" لوحده.
- **Badge لكل لابتوب** (Gaming / Creator / Business / Budget / Everyday) + جملة "Good for..." توضح الاستخدام المناسب.
- Tooltips (علامات ؟) على المواصفات التقنية في صفحة التفاصيل بتشرح كل حاجة.
- **AI Quiz** بقى خطوتين (الاستخدام + الميزانية) بدل خطوة واحدة، بتصميم أوضح بـ progress bar.

## للمستخدم اللي عارف اللي عايزه
- فلتر جديد **"I'm looking for"** (نوع الاستخدام) بالإضافة للبراند والرام والسعر.
- **Sort by** (السعر / الأعلى تقييم).
- **بحث** بيدور جوه كل المواصفات مش بس الاسم.
- **Active filter chips** تحت الفلاتر عشان تشوف وتشيل أي فلتر بضغطة واحدة.
- **Load more** بدل ما الموقع يعرض أول 50 لابتوب بس ويخفي الباقي.

## المقارنة
- شريط المقارنة تحت بيعرض صور مصغّرة (initials) لكل لابتوب مختار.
- جدول المقارنة بيحدد **باللون الأخضر** أفضل قيمة في كل صف (سعر أقل / رام أعلى / تقييم أعلى)، ومعاه زرار Remove لكل عمود.

## إضافات تانية
- **Wishlist** (قلب) بتتحفظ في المتصفح (localStorage) وليها نافذة خاصة.
- تصحيح مشكلة في الداتا سيت نفسها: عمود الـ RAM كان فيه صفوف غلط بقيم SSD (زي "1 TB SSD")، اتعملها فلترة عشان الفلتر يطلع نضيف (2GB, 4GB, 8GB, 16GB...) بدل قيم فاسدة.
- الموقع مفيهوش صور حقيقية للابتوبات (فولدر images كان فاضي)، فبدل الصور المكسورة عملت "device placeholder" احترافي: بلوك بلون مميز لكل براند + حروف الاسم، بدل أيقونة صورة مكسورة.
- تصميم كامل جديد (ألوان، خطوط، شكل الكروت) واستجابة كاملة للموبايل (فلاتر بتتحول لـ drawer جانبي).

## لو حبيت تضيف صور حقيقية
حط صور بالاسم ده: `images/<brand-lowercase>.jpg` (مثال: `images/hp.jpg`, `images/dell.jpg`) — الكود مستعد يستخدمها لو موجودة، لكن دلوقتي بيعتمد على الـ placeholder المصمم.

## تشغيل المشروع
افتح `index.html` من خلال سيرفر محلي بسيط (مش فتح الملف مباشرة، لأن الفetch لملف laptops.json محتاج سيرفر):
```
python3 -m http.server 8000
```
وبعدين افتح `http://localhost:8000` في المتصفح.
